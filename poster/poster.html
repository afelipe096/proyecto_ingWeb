OBJETIVOS / OBJECTIVES

Objetivo general

Desarrollar una plataforma web para consultar productos de tecnología y gaming, gestionar el carrito y registrar pedidos de demostración.

Objetivos específicos

Diseñar una interfaz adaptable con HTML5, CSS3 y JavaScript.

Organizar el catálogo por categorías con búsqueda, filtros y ordenamiento.

Integrar una API REST con Node.js/Express y una base de datos MySQL.

Validar solicitudes, documentar la arquitectura y automatizar pruebas.

MÉTODO / METHOD

Metodología de desarrollo

  1. Definir la estructura visual y el recorrido del catálogo.
  2. Implementar categorías, productos, filtros, carrito y pedidos.
  3. Modelar cinco tablas relacionadas en MySQL.
  4. Validar solicitudes y registrar pedidos mediante transacciones.
  5. Ejecutar pruebas automáticas de sintaxis e integración.

CONCLUSIONES / CONCLUSIONS

Nexora integra el catálogo, el carrito y el registro de pedidos de demostración en una arquitectura de tres capas.

La separación entre frontend, API y persistencia organiza las responsabilidades.

Las consultas parametrizadas y las transacciones fortalecen la consistencia de los pedidos.

La automatización permite comprobar recorridos clave y reducir regresiones.

Alcance académico. Los precios, productos y existencias son ilustrativos. No se procesan pagos ni se entregan claves digitales reales.
